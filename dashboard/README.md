# Dashboard Subsystem (Real-time Inventory Monitoring UI)

Thư mục chứa giao diện giám sát và quản lý tồn kho:
- Hiển thị tình trạng tồn kho thời gian thực từng khay/ngăn kệ.
- Biểu diễn trực quan hình ảnh camera kèm bounding box của YOLO.
- Biểu đồ biến thiên trọng lượng và số lượng tồn kho theo thời gian.
- Bảng cảnh báo trạng thái bất đồng (Disagreement Alert), thiếu hàng (Low Stock), hoặc vật thể lạ (Foreign Object).
- Giao tiếp thời gian thực thông qua MQTT / WebSocket.
