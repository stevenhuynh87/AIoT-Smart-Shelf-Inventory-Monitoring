# Senior Thesis (Khóa Luận Tốt Nghiệp)

Thư mục lưu trữ các tài liệu phục vụ báo cáo khóa luận:
- `manuscript/`: Báo cáo khóa luận (LaTeX / Markdown / DOCX theo định dạng quy định của nhà trường).
- `presentations/`: Slide thuyết trình báo cáo tiến độ và bảo vệ tốt nghiệp.
- `figures/`: Sơ đồ khối hệ thống, hình ảnh kết quả thực nghiệm, biểu đồ thống kê.
- `references/`: Danh mục tài liệu tham khảo, trích dẫn chuẩn IEEE (BibTeX).
