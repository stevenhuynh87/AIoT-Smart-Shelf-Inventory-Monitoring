# Documentation

Thư mục lưu trữ toàn bộ tài liệu kỹ thuật của dự án:
- `architecture.md`: Thiết kế kiến trúc tổng thể phần cứng và phần mềm.
- `hardware_schematic/`: Sơ đồ nguyên lý đấu nối ESP32, cảm biến tải trọng HX711, camera.
- `api_spec.md`: Đặc tả giao thức MQTT topic và payload định dạng JSON.
- `experiment_protocol.md`: Kịch bản thử nghiệm đánh giá độ chính xác trong các điều kiện (chiếu sáng yếu, che khuất một phần, đặt nhầm sản phẩm).
